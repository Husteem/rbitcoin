Security

- **`GET /tx/:txid/outspends` no longer costs several random reads per output, without limit.** It resolved the txid again and read each output's spender, spender txid and block status separately, for up to ~111,000 outputs in one request. It now resolves the txid once, reads the spent slots in one batch, and reads each spending tx's txid and each block's status once. Unpaged, it still answers every output, as Esplora does. An outspends reply over 10,000 entries, from this route or the bulk outspends routes, is built under the node's single heavy turn (the one heavy unpaged scripthash joins take), so only one such reply is built at a time and the others wait. `?start_index=N` (dialect) answers the 10,000 outputs from `N` without the turn. The bulk outspends routes take the same batched read. ([#1953](https://github.com/rbitcoin-org/rbitcoin/issues/1953))
