- **A whole confirmed history above `--max-sh-creates` for a trusted local caller.** On the Esplora unix socket, `GET /internal/scripthash/:hash/history` and `GET /internal/address/:address/history` return every confirmed transaction of the script as Electrum `get_history` rows (`[{"tx_hash","height"}, ...]`, height then txid bytes), with `?asof=` and the chain-tip headers of the totals route. They skip the `--max-sh-creates` refusal and do not build the whole list first: the node joins 4096 creates at a time and writes each wave's rows before reading the next, so a long list no longer races a timeout or holds the full join in memory. A failure after the headers aborts the body. TCP Esplora does not mount them and Electrum is unchanged, so an explorer can copy a large address's list without raising the cap for a public Electrum port. Probe: 64 zeros as the scripthash is 200 `[]`, and 404 on an older node.
